# Install TW4

How to get the API running on a machine. Pick **one** path: native (Node) or Docker.

If you never ran TW4, start with the [Quickstart](/docs/quickstart) instead. This page is the longer install reference.

## Prerequisites

| Tool | Native | Docker | Version |
| --- | --- | --- | --- |
| Git | Yes | Yes | 2.40+ |
| Node.js | Yes | No | 20+ |
| npm | Yes | No | 10+ |
| Docker Desktop | No | Yes | 24+ |
| Docker Compose | No | Yes | v2 |

## Native

### Clone

```bash
git clone https://github.com/Brayden-Code-4/TW4-Delivrable.git
cd TW4
```

### Create `.env`

```bash
cp .env.example .env
```

PowerShell: `Copy-Item .env.example .env`

Set `API_KEY`. Change `PORT` only if 3000 is already used.

### Run

```bash
npm install
npm start
```

Check:

```bash
curl http://127.0.0.1:3000/health
```

Stop with `Ctrl+C`.

## Docker

You do not need Node on the host.

```bash
git clone https://github.com/Brayden-Code-4/TW4-Delivrable.git
cd TW4
cp .env.example .env
docker compose up --build
```

Compose maps port `3000`, keeps tasks in the `tw4_data` volume, and checks `/health` every 30s.

Then:

```bash
curl http://127.0.0.1:3000/health
docker compose ps
```

The `tw4-api` container should show as running. The API listens on port 3000 inside the container too.

GitHub Actions builds this image and curls `/health` on every push (`ci.yml`). Run `docker compose up --build` on a machine that has Docker before you demo it.

Without Compose, after a local build:

```bash
docker build -t tw4-api:1.0.0 .
docker run --rm -p 3000:3000 -e API_KEY=change-me-now --name tw4-api tw4-api:1.0.0
```

Stop Compose with `Ctrl+C`, then `docker compose down`.

## Limits

- GET list and GET one task have no auth. Local machine only.
- `data/tasks.json` has no lock. One process.
- `API_KEY=change-me-now` is an example, not a secret.

## Environment

Same names as in `.env.example`:

| Name | Required | Default | Notes |
| --- | --- | --- | --- |
| `HOST` | No | `0.0.0.0` | Keep this in Docker |
| `PORT` | No | `3000` | Host port for Compose too |
| `API_KEY` | For writes | `change-me-now` | Header `X-API-Key` |
| `DATA_FILE` | No | `./data/tasks.json` | `/app/data/tasks.json` in Docker |
| `LOG_LEVEL` | No | `info` | `error`, `warn`, `info`, `debug` |
| `NODE_ENV` | No | `development` | Compose sets `production` |

## If it fails

| What you see | What to try |
| --- | --- |
| `connection refused` on `/health` | The process is not listening. Check the start logs. |
| `401 unauthorized` | Header key ≠ `API_KEY` in `.env` |
| Port already allocated | Change `PORT` in `.env` and restart |
| Docker not found | Install Docker Desktop, or use the native path |
