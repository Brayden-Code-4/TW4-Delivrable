# GET /api/core/service/search

List services. The generated table lists **GET**. The official API intro shows the GUI sending **POST** JSON to the same path (`current`, `rowCount`, `searchPhrase`) from **System → Diagnostics → Services**. Both are documented so a demo is not a surprise.

Needs Basic auth.

## POST body the GUI uses

```json
{"current":1,"rowCount":7,"sort":{},"searchPhrase":""}
```

## Response

JSON with `total`, `rowCount`, `current`, `rows` (each row has `id`, `running`, `name`, …).
