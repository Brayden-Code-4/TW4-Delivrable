# OpenAPI spec

Machine-readable **subset** of the routes this handbook walks (OpenAPI 3.0.3). The generated OPNsense index stays the full list.

- File in the repo: `website/static/openapi.yaml`
- Served with the docs: [openapi.yaml](/openapi.yaml)

Import into [editor.swagger.io](https://editor.swagger.io/) if you want try-it-out against `https://192.168.1.1` (the appliance must be up, and you must pass Basic auth).
