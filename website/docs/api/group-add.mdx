# POST /api/auth/group/add/

Create an access group. Copied from the official how-to (GUI **System → Access → Groups**, then DevTools). Needs Basic auth and access to that page.

## Body

```json
{
  "group": {
    "name": "HelloWorld",
    "description": "HelloWorld",
    "priv": "page-system-login-logout",
    "member": "0"
  }
}
```

## Response

```json
{"result":"saved","uuid":"569118e0-006b-4a2d-8eb6-332d29300a2a"}
```

The UUID in the official page is an example. Yours will differ.
