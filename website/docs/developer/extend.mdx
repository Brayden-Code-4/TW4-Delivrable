# Extend OPNsense

You do not patch this docs repo to add a firewall feature. You work in [opnsense/core](https://github.com/opnsense/core) or a plugin.

## Plugin

Plugins install from **System → Firmware → Plugins**. Community (tier 3) plugins are hidden until you tick that box. Examples used in the official virtual page: `os-virtualbox`, `os-vmware`.

A plugin that follows the MVC layout gets API routes for free — same `/api/<module>/...` rule.

## Script against the API

For automation, keep a small client (see [Integrate](/docs/developer/integrate)). Do not scrape the HTML GUI.

## Do not

- Invent a Docker image and call it official.
- Commit API secrets next to the docs.
- Document a POST body you never saw in the Network tab or in the official how-to.
