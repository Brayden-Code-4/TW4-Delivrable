Quickstart (10–15 min)What / who / why

What

A local REST API for a writing backlog. Title plus status (todo, doing, done). Data in data/tasks.json. Not a hosted cloud product.

About TW4

Who

Developers and technical writers on one machine. Script it with curl, Node fetch, or Python urllib.

Developer guide

Why docs

The header is X-API-Key, statuses are three strings, ids are UUIDs. Those three details fail on a clean clone without a guide.
